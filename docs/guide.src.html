Eternalgy O&M Dashboard

User Guide

Desktop app version 1.1.0  ·  November 2026  ·  Engineering — Electrical and O&M

The O&M Dashboard is the Engineering department's working tool for operation & maintenance and engineering records. In one app you can log site issues and track them to completion, schedule technician visits, produce rectification reports and solar saving reports for clients, record drawings, load profile jobs, O&M manuals and testing & commissioning (T&C) reports, and export summaries for management.

This guide walks through each screen in the order you will use them. Screens are shown with sample data — the client names are made up.

Important — connect to NUrul_DB first

Once a PC is connected to NUrul_DB (section 1.3), every record is shared with the whole team and the screens say “Shared with your team”. Until then the app saves on this computer only (“Saved on this device only”) and colleagues cannot see your work.

Part 1

Install and update

1.1Install

  1. Open the releases page: github.com/NurulAqilahSaifulBahril/Engineering/releases.
  2. Under Assets, download Eternalgy-OM-Dashboard-Setup-<version>.exe (about 80 MB). You only need the .exe; the other files are used by the updater.
  3. Run the file. If Windows shows “Windows protected your PC”, click More info then Run anyway — the installer is not code-signed yet, so Windows does not recognise the publisher.
  4. Choose where to install (the default is fine) and finish. The app is added to the Start menu and the desktop as Eternalgy O&M Dashboard.

1.2Updates

  • Each time the app opens it checks GitHub for a newer version and downloads it in the background.
  • When the download is ready you will see “Update ready”. Click Restart now, or Later to install it the next time you close the app. Save your work first — the app never restarts on its own.
  • To check yourself: Help → Check for Updates…. Help also shows the version you are on.
  • Updating keeps all your saved records and drafts.

1.3Connect to NUrul_DB (once per PC)

Shared records live in the company database, NUrul_DB. The installer does not contain the database key — your admin gives you a small connection file (for example om-db.env) privately. Keep it to yourself: anyone with the file can reach the database.

  1. Click File → Database Connection… and choose the connection file.
  2. The app tests it. On success you see “Connected to NUrul_DB” and the app reloads; the dashboards now say “Shared with your team”.
  3. Click File → Your name… and type your name. It is shown as Logged by on records you save.
  • The File menu always shows whether this PC is connected. Disconnect from NUrul_DB takes it off again.
  • Colleagues' changes appear within about 15 seconds, and straight away when you switch back to the app.
  • Records saved on a PC before it was connected stay on that PC and are not shown while connected.

2.1How reports work

Reports (saving, rectification, O&M manual, T&C) share the same layout: details on the left, a live preview of the finished report on the right. The preview updates as you type. Three buttons sit above the preview:

ButtonWhat it does
Submit reportSaves it as final. It is counted on the dashboards and the “DRAFT – not submitted” badge disappears from the report.
Save draftKeeps your work to finish later. Drafts are listed on the O&M Dashboard under Drafts (not submitted) and are not counted as produced.

Tip

Submit before you print, so the PDF does not carry the orange DRAFT badge.

Part 3 · O&M

Site issues

O&M → Site Issue is the ticket list for every problem reported by a client or spotted on monitoring. Each ticket gets a number such as SI-261127-140923 (date and time logged).

3.1Log a new issue

  1. Click + Log issue.
  2. Choose the Source: Client reported or Monitoring.
  3. Fill in the client / site name, contact, address, system size, inverter size and model, and agent.
  4. Pick the Issue type and describe what the client reports or what was found.
  5. Tick System fully down or Safety risk if they apply, and add up to 3 pictures.
  6. For an old (backlog) issue, set the earlier date it was reported and its current status, and use the note to say how it was solved.
  7. Click Submit issue.

3.2Urgency is set automatically

UrgencyWhen
UrgentNo generation · Inverter fault · Leakage / safety / damage — or any issue with System fully down or Safety risk ticked
NormalTripping · Low generation
LowMonitoring / app · Billing / TNB · Other

3.3Find and follow up tickets

  • The cards at the top count Open, On monitoring, Completed and Urgent (not completed) tickets.
  • Filter the list with the status buttons (All / Open / On monitoring / Completed / Urgent) and the issue-type buttons, or search by client, ticket number or type.
  • Click a ticket to open its detail.

In the ticket detail you can:

  • Update the status — Open → On monitoring → Completed. Set the rectification date, add an optional note, then Save update. Aging counts the days from logging to completion.
  • Arrange visit — schedule a technician (section 4).
  • Create rectification report — starts a report already filled with this ticket's details (section 5).
  • Reopen with a new issue — appears on completed tickets when the problem comes back.
  • Edit details — correct the address, system size, agent or inverter model.
  • Activity — a history of everything done on the ticket.

3.4Site issue summary

The Site issue summary card counts issues reported, still open, rectified and average days to rectify, broken down by issue type. Choose Weekly / Monthly / Yearly and a date, then Download CSV or Print / Save as PDF.

Not available in the desktop app

Import issues (“Read with Claude”) only works when the dashboard is opened inside Claude. In the desktop app it shows “Reading is not available here” — log issues with + Log issue instead.

Part 4 · O&M

Site visits and the calendar

4.1Arrange a visit

  1. Open the ticket and click Arrange visit.
  2. Enter the visit date, time (optional), technician, proposed action, any spare part needed and a note.
  3. Click Save visit. The visit appears on the ticket, in its Activity history and on the calendar. Remove visit cancels it.

4.2Calendar

O&M → Calendar shows every technician visit for the month. Move between months with ‹ ›, jump back with Today, and pick one person in Technician to see only their visits.

  • Amber = scheduled, red = overdue, green = completed. Click a visit to open its ticket.
  • Not yet scheduled (below the calendar) lists open issues that have no visit yet — work through this list so nothing is missed.
  • Daily report (or Report on a day) gives a printable list of that day's visits for the technicians.
Part 5 · O&M

Rectification reports

A Site Issue Rectification Report records what was found on site and what was done, with before and after pictures and signature lines for the technician and the customer. Each report gets a number such as SIR-261127-1404.

  1. Best way: open the ticket and click Create rectification report — the client, address and issue are filled in for you. You can also start one from O&M → Rectification Report or + Rectification report on the O&M Dashboard.
  2. Fill in who attended, the dates (reported, attended, completed) and the status.
  3. Describe the issue finding at site and the rectification work done.
  4. Add before and after pictures.
  5. Submit report, then Print / Save as PDF for the customer to sign. New / clear starts a fresh report.
Part 6 · O&M

Solar saving reports

O&M → Saving Report turns a client's TNB bill and solar figures into a Solar Saving Analysis Report: bill without solar, bill with solar under ATAP and/or NEM, monthly and yearly saving, system performance and a full bill breakdown.

6.1Make a report

  1. Enter the PIC (who prepared it — remembered for next time).
  2. Choose the Tariff type to match the bill: ToU (Peak / Off-Peak) or Standard (non-ToU). The bill and export boxes change to match.
  3. Choose the Scheme to show: ATAP and NEM (compare), ATAP only or NEM only.
  4. Client: company, client name, site address, bill month.
  5. System: system size (kWp), inverter capacity (kW), billing period (days) and, optionally, system cost — which adds a payback estimate.
  6. TNB bill: import (peak and off-peak, or total), AFA, and green tariff kWh if any. Optionally key in the actual TNB current charge; the app then shows how close its calculation is to the real bill.
  7. Solar: total solar generation and export (kWh (E) on the bill), plus NEM carried-forward credit or ATAP limit if they apply.
  8. Attach the TNB bill and the solar generation record (PDF or picture). They are added to the end of the report as supporting documents.
  9. Check the report on the right, then Submit report and Print / Save as PDF.
Try it first

Sample: ToU and Sample: Non-ToU fill in a complete example. Clear empties the form.

6.2Checks the app does for you

  • “Export is higher than total solar generation” — one of the two figures is wrong.
  • “Export is the same as the Baki balance” — you probably typed the Baki (balance) into export. Export should be the kWh (E) meter reading.

6.3Tariff rates

TNB rates (energy, capacity, network, retail charge, the 800 kWh split, etc.) are pre-filled under Tariff rates (pre-filled) following TNB domestic rules from 1 Sep 2026. Only change them if TNB revises its tariff.

Not available in the desktop app

The Auto-fill buttons that read figures from the uploaded bill need Claude. In the desktop app they show “Auto-read is not available in this view” — key the figures in by hand. The uploaded pictures still appear in the report.

Part 7 · O&M

O&M dashboard

O&M → Dashboard is the overview for the O&M team:

  • + Saving report and + Rectification report start a new report.
  • Drafts (not submitted) — open one to carry on where you left off.
  • Site issues — open, on monitoring, completed and urgent counts.
  • Saving reports — number produced, this month, total and average saving shown, a 6-month chart, and a searchable list of every report (search by client or address). Click Open to reopen a report or Delete to remove it.
  • Site issue rectification reports — counts by status and the list of reports.
Part 8 · Engineering

Drawings

Engineering → Submission Drawing and Installation Drawing keep a daily count of drawings completed.

  1. In Log drawings done, pick the date and enter how many Residential and C&I drawings were done.
  2. Enter the PIC (who did them) and an optional note, then click Add.

The page then shows totals for today, this week, this month and this year, a daily chart for the month, a table by date and a breakdown by PIC. Use Download CSV (month) or CSV (whole year) to export.

The Engineering → Dashboard combines drawings, load profile jobs, O&M manuals and T&C jobs, with a Drawing summary you can export by day, week, month or year.

Part 9 · Engineering

Load profile

Engineering → Load Profile tracks requests to install a load-logging device at a client's site, and which device is where.

9.1New request

  1. Click + New request.
  2. Enter the client name, agent, phase, address and an optional note, then Save.

9.2Arrange the device

  1. Switch to the Calendar view. New requests are listed under To arrange.
  2. Pick the request, choose the device, the install date, the dismantle date and the PIC. A device already booked on those dates is marked (booked) in the list.
  3. Save arrangement. The job moves to Scheduled.

Status follows the dates automatically: Open before the install date, In progress from the install date, Completed after the dismantle date. Devices in use today shows how many of the devices are out on site. To record a job that is already finished, enter its device, PIC and the past dates.

Part 10 · Engineering

O&M manuals

Engineering → O&M Manual writes a complete Operation and Maintenance Manual for the client from the system details — introduction, how the system works (with a diagram), the scheme, safety, operation, maintenance and warranty. Each manual gets a reference such as OM-261127-1404.

  1. Project: client, address, system type (On-Grid, Off-Grid, SELCO, Hybrid + BESS), scheme (ATAP, NEM, SELCO), commissioning date, prepared by. The text of the manual changes to suit the system type and scheme.
  2. System: size, phase, mounting, panel and inverter brand / model, quantities, monitoring app.
  3. Warranty years, plus warranty documents.
  4. Maintenance: cleaning frequency.
  5. Attach drawings, the scheme certificate and system photos (PDF or picture). Drawings are placed after the Maintenance section; warranty documents go in the Warranty section.
  6. Company name, phone and email for the contact page.
  7. Submit manual, then Print / Save as PDF. New manual starts another.
Tip

Any box left empty appears as a dash (—) in the manual, so check the preview for dashes before you print.

Part 11 · Engineering

Testing & commissioning (T&C)

Engineering → T&C records testing and commissioning jobs and produces a Testing & Commissioning Report.

  1. Click + New T&C job.
  2. Job: client, address, date of test, PIC (tested by), status (Open / In progress / Completed).
  3. System: customer type (Residential / C&I), phase, system size, panel model, module Voc and Isc from the datasheet.
  4. Test settings: insulation test voltage, tolerance, irradiance and test instrument.
  5. Enter the measured string values. The app works out the expected Voc / Isc and marks any string outside the tolerance for checking.
  6. Submit report (or Save draft), then Print / Save as PDF. Close returns to the job list.

The job list can be filtered by status and searched by client, address or PIC.

Part 12

Main dashboard and summaries

The Dashboard in the sidebar is the management view across both areas. Each card shows the count for one tab — click a card to go there.

12.1Export summary

  1. Choose the period: Daily, Weekly, Monthly or Yearly, and the date inside it.
  2. The table shows every tab's count with Open / On monitoring / Completed.
  3. Download CSV for Excel, or Print / Save as PDF.

Export all summary (PDF) (top right) builds one printable summary covering all tabs.

12.2PIC work done

Shows the work recorded against each person in charge — drawings, load profile jobs, site visits, rectification reports and O&M manuals. Choose the period and a PIC (or All PICs), then export as CSV or PDF. This only works if the PIC boxes are filled in consistently, so always use the same spelling of each name.

Part 13

Good to know

13.1Where your data is kept

This PC is…Your records are…
Connected
“Shared with your team”		Saved in NUrul_DB. Everyone connected sees and can edit them, and they are there on any PC you connect. Pictures are stored in NUrul_DB too.
Not connected
“Saved on this device only”		Saved inside the app on this computer only. Updating the app keeps them; uninstalling with app data removed, resetting Windows or a failed disk loses them.
  • A connected PC needs the internet to load and save records. If NUrul_DB cannot be reached when the app opens, it falls back to “Saved on this device only” — check the label before entering work, and reload once you are back online.
  • Whichever mode you use, save finished reports with Print / Save as PDF and export summaries with Download CSV for your records.

13.2Features that need Claude

The dashboard was first built to run inside Claude. Two features depend on that and do not work in the desktop app:
