Install it

Open the downloaded file (from your browser's downloads, or the Downloads folder).

Windows may show a blue “Windows protected your PC” box, because the app is new to Windows. It is safe to continue: click More info, then Run anyway.

Then follow the installer: Next → Install → Finish. The app opens, and a shortcut called Eternalgy O&M Dashboard is added to your desktop and Start menu.

That's it — there is nothing to set up. The app is already connected to the company database (NUrul_DB): the pages say “Shared with your team”, so everyone sees the same records.

How updates work

A

When the “Update ready” box appears

Update ready
i
Version x.x.x has been downloaded.
Restart now to install it, or it will install the next time you close the app.
Restart nowLater
  • Restart now — save what you are typing first, then click. The app closes, installs and reopens (about a minute).
  • Later — keep working. The update installs by itself the next time you close the app.
B

Check for an update yourself

Click Help → Check for Updates…. If there is a new version it downloads and the box above appears; otherwise you see “You're on the latest version”. The last line of the Help menu shows the version you have.

Good to know

Updates need the internet. If the app was offline when it opened, it simply checks again next time. Never uninstall to update — just let the app update itself, or download the newest Setup file from the link on page 1 and run it over the top.
