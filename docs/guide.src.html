Install

1

Click the link to download

It always opens the newest version on GitHub — keep this guide and use the same link every time.

Download link — click here Engineering — Electrical & O&M Portal
2

On GitHub, download the Setup file

Under Assets, click Eternalgy-OM-Dashboard-Setup-x.x.x.exe. Ignore the other files.

x.x.x is the version number and changes with each release — just take the Setup .exe on the page the link opens.

3

Install it

Open the downloaded file. If Windows shows “Windows protected your PC”, click More info then Run anyway — the app is safe, just new to Windows.

Then Next → Install → Finish. The app opens and an Eternalgy O&M Dashboard shortcut is added to your desktop and Start menu. Nothing else to set up — it is already connected to NUrul_DB and shared with your team.

How updates work

A

When the “Update ready” box appears

  • Restart now — save what you are typing first. The app closes, installs and reopens (about a minute).
  • Later — keep working. It installs by itself the next time you close the app.

Good to know

Updates need the internet; if the app was offline, it checks again next time. Never uninstall to update — let the app update itself, or run the newest Setup file from the link over the top.
